# Паспорт проекта



## 1. Название проекта
магазин обуви ediki


## 2. Проблема
не сделаем приложние, потому что надо написать правильно оформить каталог товаров для пользователя иначе менеджер не сможет обновлять товары 


## 3. Пользователи
клиент магазина — выбирает товар и оформляет заказ, менеджер — ведёт каталог и остатки; администратор — управляет пользователями и правами


## 4. Цель проекта
дать клиенту хороший выбор товаров и возможность заказать товар и выдача в магазине,а менеджеру видеть сколько осталось товаров 


## 5. Метрики успеха
время оформление заказа - < 3 минут;
клиент находит товар по своим критериям - < 4 кликов


## 6. Границы (что НЕ делаем)
нет мобильного приложения,нет окна оплаты заказа


## 7. Риски
сложно придумать много товаров: берем ассортимент из открытых источников
